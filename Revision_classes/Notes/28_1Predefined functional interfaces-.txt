Predefined functional interfaces:-
================================
1. Predicate
2. Function
3. Consumer
4. Supplier

Predicate:-
===========
It is a Boolean valued function. It is used to check some conditions.
It is introduced in java 1.8 and available in java.util.function
It contains one abstract method "test()"

         interface Predicate<T>{
            boolean test(T, t);
          }
test() takes input performs conditional check and return true/false

Function:-
==========
            It can return any type.
          
            interface Function<T, R>{
              R apply(T t);
          }

Consumer:-
=========
Consumer accepts values and performs required action but does not return anything.

          interface Consumer<T>{
                void accept(T t);
                }

Supplier:-
=========
 Supplier does not accept anything as input but returns something. It contains only one abstract method get(), It does not contain any default or static methods

        interface Supplier<R>{
            R get();
          }

Bi-Functional interfaces:-
=========================

These take two arguments as input.
1. BiPredicate
2. BiFunction
3. BiConsumer

BiPredicate:-
============

    
 interface BiPredicate<T, U>{
   public boolean test(T t, U u);
   }

BiFunction:-
===========

 interface Function<T,U, R>{
              R apply(T t , U u);
          }

BiConsumer:-
============

interface Consumer<T, U>{
                void accept(T t, U u);
                }
