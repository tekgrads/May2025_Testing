Functional Interface:-
=====================

If the interface contains only one abstract method then it is functional interface, but it can have any default or static methods
  Runnable -> run()
  Callable ->call()
  Comparable -> compareTo()

= ===============================

from java 1.8 interface takes concrete methods called default methods.
Should declare method with default keyword
                           --------


We can override these methods in implementation classes but we should not keep default there we should override as public void.
 If we want to use the interface default method directly we should call as 
   interface name. super. method name

Static methods inside interface:-
=================================
   from java 1.8 interface static methods.
Should declare method with static keyword
                           --------
These static methods are not available for implementation class. We cannot call them by implemented class obj reference. If we want to invoke them we should call them by interface name. We cannot override these methods ,if we override them then there are implemented class own methods. We can change the scope then also no error bcoz these are not overridden methods.
   In interface we can declare main method and can execute main directly
