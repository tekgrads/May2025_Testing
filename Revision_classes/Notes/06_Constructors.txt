Constructor and types of constructors
=====================================
- A constructor is a kind of method  whose name is same as class name and does not have return type.
- It is used for initializing an object's NSVs with given values.

- In Java, object is created by using 'new' operator and 
  the object is initialized by using constructor.

- In Java, constructor is not a constructor, it is an initializer, 
  it does not construct object, it only initializes the object 
  which is created by new keyword.


- Rules in creating constructor
	1. Its name must be same as class name
	2. It must not have return type
	3. All 8 ELMs are not allowed
	4. 'return value;' is not allowed

- Rules in calling a constructor
	1. we must call it by using new keyword
	2. Whether to pass arguments or not 
	   is depending on constructor parameters

- Constructors are not executed because they are not called in main method

- We must call constructors by using new kw and by passing required arguments 
  based on constructor parameters


		

Types of constructors 
	1. Default constructor 
	2. No Param constructor or no-arg constructor or nullary constructor 
	3. Parameterized construct 

- Default constructor
    - A constructor that is generated by compiler is called default constructor 
    
    - Compiler generates default constructor only if a developer not defined 
      constructor in this class 
    
    - If this class contains either no-param constructor or param constructor   
      compiler does not generate default constructor

Q) Can we declare constructor as private?

Yes, we can declare constructor as private. All four accessibility modifiers are allowed to
constructor. We should declare constructor as private for not to allow user to create object
from outside of our class. 


Q) Is constructor definition mandatory in class?

No, it is optional. If we do not define constructor compiler define constructor.

Q) Can we define empty class? If so, is it really an empty class?
Yes we can define empty class, but after compilation it has constructor definition that is placed
by compiler. So really it is not an empty class.
